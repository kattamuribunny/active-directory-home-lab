Active Directory Home Lab

Project Overview

Built a hands-on Active Directory home lab using Windows Server and Oracle VirtualBox to practise user and group management, Group Policy, shared folder permissions, and basic troubleshooting.

Lab Environment

- Virtualization: Oracle VirtualBox
- Operating System: Windows Server
- Domain: "company.local"
- Directory Service: Active Directory Domain Services (AD DS)

Implementation

1. Active Directory Setup

- Installed Windows Server in Oracle VirtualBox.
- Installed and configured Active Directory Domain Services.
- Promoted the server to a Domain Controller.
- Created the "company.local" domain.

2. Organizational Units and User Management

- Created OUs for IT, HR, Finance, and Management.
- Created department-based user accounts.
- Created security groups and assigned users to the appropriate groups.

3. Group Policy Management

- Created and configured an IT Group Policy Object ("IT_Policy").
- Applied Control Panel restrictions to IT users.

4. Shared Folders and Permissions

- Created department-specific shared folders.
- Configured NTFS and share permissions.
- Tested folder access using department user accounts.

5. Troubleshooting

- Practised troubleshooting login issues.
- Resolved network share access problems.
- Checked and corrected file permission issues.

Skills Practised

- Windows Server
- Active Directory Domain Services (AD DS)
- User and Group Management
- Organizational Units (OUs)
- Group Policy Objects (GPOs)
- NTFS and Share Permissions
- Oracle VirtualBox
- Basic IT Troubleshooting

Project Purpose

This project helped me gain practical experience with Windows Server administration and understand common IT support tasks in a simulated business environment.
